快速开始

三步完成第一个 Mod 的中文化

1

填写 API 设置

填入接口地址、API Key 与模型，点"测试连接"确认可用。默认已填好 DeepSeek 配置。

2

选择 Mod 文件夹

点"扫描"自动识别可翻译文件与文本条数，双击条目可勾选/取消。

3

开始翻译

点"▶ 开始翻译"，进度实时显示；完成后到输出文件夹取用，占位符与格式码完整保留。

命令行模式（脚本化 / 批量处理）

适合集成到构建流程，或对大量 Mod 定时翻译：

GameModTranslator.exe --cli --input D:\mods\MyMod --output D:\mods\MyMod_zh ^ --api-key sk-xxx --model deepseek-chat --lang 简体中文
GameModTranslator.exe --cli --input D:\mods\MyMod --list :: 仅扫描 GameModTranslator.exe --cli --input D:\mods\MyMod --inplace --api-key sk-xxx :: 覆盖原文件(自动备份 .bak)

本地模型（免费离线）

接口地址指向本地服务即可，API Key 随便填：

本地服务接口地址模型名示例
Ollamahttp://localhost:11434/v1qwen2.5:7b
LM Studiohttp://localhost:1234/v1界面中加载的模型
vLLMhttp://localhost:8000/v1Qwen/Qwen2.5-7B-Instruct
llama.cpphttp://localhost:8080/v1启动时指定的模型名
建议：本地翻译质量与模型大小直接相关，推荐 7B 及以上模型（如 Qwen2.5-7B-Instruct）；小模型偶尔丢失占位符时，软件会自动重试并在日志中警告。
